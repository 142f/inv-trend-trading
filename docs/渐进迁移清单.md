# 渐进迁移清单

| 能力 | 当前权威入口 | 兼容入口 | 删除条件 |
|---|---|---|---|
| 批量回测 | `inv_trend.application.backtest` | `application.strategy_backtest`、`BacktestService` | 连续一个发布周期、生产零引用、历史制品对账通过 |
| 每日分析 | `application.daily` 与 `core.strategy.daily` | `daily_analysis`、`daily_stages`、`daily_artifacts` | CLI 和外部调用迁移、canonical Golden Master 通过 |
| 历史数据 | `HistoricalDataService` | 时点/v1 数据入口 | 数据版本、可用时间和隔离测试全部通过 |
| 结构化存储 | Repository/Artifact Port | v1/v3 存储模块 | 迁移器完成、真实历史样本校验、入口点归零 |

## 删除门禁

1. 使用 `scripts/遗留模块引用审计.py` 检查源码、测试和 `pyproject.toml`。
2. 动态导入与历史制品模块名另行检查，不能只依赖文本搜索。
3. 运行兼容测试、Golden Master 和全量测试。
4. 删除操作必须独立提交，并附恢复方式。

当前版本不满足批量删除 v1/v3 模块的条件。
