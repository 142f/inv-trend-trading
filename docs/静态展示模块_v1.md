# 静态展示模块 v1

固定 HTML 展示页的唯一归属模块：`src/inv_trend/observability/静态展示/`。
模块只做页面资源、导出与只读预览，不计算行情、指标或回测结果。

## 页面目录

| id | 页面 | 类型 | 资源路径 |
|---|---|---|---|
| `pipeline-board` | 数据管理流水线任务看板 | 固定资源 | `pages/数据管理流水线任务看板_v1.html` |
| `audit-report` | 美股前100指标审计验收汇报 | 固定资源 | `pages/美股前100指标_审计验收汇报.html` |
| `refactor-acceptance-s1-s5` | S1–S5 结构修复验收 | 固定资源 | `pages/refactor-acceptance-s1-s5/refactor-acceptance-s1-s5.html` |
| `us-top100` | 美股前100指标看板 | 运行时生成 | `deliverables/美股前100指标看板.html` |

固定资源的源文件入库；美股前100看板含运行时数据，仍由
`scripts/美股前100指标.py` 写入 `deliverables/`，不入库。

## 使用

```bash
static-pages list
static-pages serve --port 8765
static-pages export --output <目录>
static-pages export --output <目录> --page pipeline-board
```

- `serve` 只绑定 `127.0.0.1`，只读，不写 `data/`、`processed_data/`、`deliverables/`。
- 索引页 `/` 列出 4 个页面；页面路径为 `/pages/<相对路径>`。
- `export` 不带 `--page` 时导出全部固定资源，并在生成产物存在时一并复制
  `美股前100指标看板.html`、`美股前100指标数据.json`、`美股前100指标_回执.json`。
- 未生成美股前100看板时，索引页标注“需先生成”；单页导出该页会报缺失。

## 资源打包

`pyproject.toml` 的 `[tool.setuptools.package-data]` 显式列出新包的 HTML、JS、字体和
许可证文本。新增页面或资源时必须同步更新该列表，否则 wheel 安装后预览会缺文件。
