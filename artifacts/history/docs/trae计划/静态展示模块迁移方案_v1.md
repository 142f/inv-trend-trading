# 静态展示模块迁移方案 v1

日期：2026-11-03
范围：把当前 4 个固定 HTML 展示页收敛到一个独立模块，提供生成、导出和本地预览服务；不改变行情、指标与回测计算。

## 1. 摘要

- 新增 `src/inv_trend/observability/静态展示/` 子包，作为固定展示页的唯一归属。
- 3 个固定页面及其静态资源迁入包的 `pages/` 目录并入库；美股前100看板的模板从脚本迁入模块，生成产物仍写 `deliverables/`。
- 新增 `static-pages` CLI：
  - `list` 列出页面目录；
  - `serve` 在 `127.0.0.1` 提供本地预览；
  - `export` 把固定页面与可用的生成产物导出到指定目录。
- 现有 `scripts/美股前100指标.py` 改为调用模块渲染函数，保留 `_page` 兼容别名，像素基线不变。
- 新增 `docs/静态展示模块_v1.md`，其中包含完整迁移清单和引用变更记录。

### 4.2 预览服务

- `/`：渲染 4 页索引，显示页面标题、说明、可用状态和链接。
- `/pages/<relative>`：
  1. 先查包内 `pages/` 资源，命中即返回；
  2. 未命中且路径在 `GENERATED_FILES` 白名单内，则从 `root/deliverables/` 读取；
  3. 其余返回 404。
- 路径安全：拒绝绝对路径、`..`、隐藏文件段；只允许 `.html/.js/.css/.ttf/.txt/.json`。
- 响应头：`Cache-Control: no-store`、`X-Content-Type-Options: nosniff`、正确 `Content-Type`。
- 服务端只读，不写 `data/`、`processed_data/`、`deliverables/`。

### 4.4 CLI 与打包

新增 `src/inv_trend/cli/静态展示.py`：

```bash
static-pages list
static-pages serve --port 8765 [--root .]
static-pages export --output <目录> [--page <id>] [--root .]
```

- `list`：输出 id、标题、类型、路径。
- `serve`：打印实际地址后阻塞；CLI 端口限 1–65535，`create_server` 允许 0 供测试取随机端口。
- `export`：不带 `--page` 时导出全部；固定页复制包资源；生成页仅在 `deliverables/` 存在时复制，指定单页缺失时抛 `FileNotFoundError`，全量导出则跳过并汇总缺失项。

`pyproject.toml`：

- 在 `[project.scripts]` 增加：
  ```toml
  static-pages = "inv_trend.cli.静态展示:main"
  ```
- 在 `[tool.setuptools.package-data]` 增加：
  ```toml
  "inv_trend.observability.静态展示" = [
    "pages/*.html",
    "pages/refactor-acceptance-s1-s5/*.html",
    "pages/refactor-acceptance-s1-s5/assets/*.js",
    "pages/refactor-acceptance-s1-s5/_shared/js/*.js",
    "pages/refactor-acceptance-s1-s5/_shared/fonts/*.ttf",
    "pages/refactor-acceptance-s1-s5/_shared/fonts/*.txt",
  ]
  ```

## 6. 假设与边界

- 3 个固定页面没有数据驱动生成逻辑；“生成”表现为从包资源导出副本，不虚构模板引擎。
- S1–S5 的字体、ECharts、Mermaid 约 5.4 MB，随包入库；接受仓库与 wheel 体积增加。
- 美股前100看板的 1.17 MB HTML 含运行数据，不入库；新克隆中预览索引会标注“需先生成”，生成命令仍为 `python scripts/美股前100指标.py`。
- `.trae/documents/` 中旧路径属历史规划记录，不批量改写；新文档记录迁移后的权威路径。
- 本次不自动提交；完成后汇报变更，提交需另行确认。
