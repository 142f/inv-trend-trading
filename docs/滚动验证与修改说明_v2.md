交付工程 **0.3.0rc2／框架B6／滚动策略_v2，状态为Research RC，不是生产Final**。实际完成6轮框架修改验证、12轮预注册策略候选池迭代。新核心链路具备可复核的历史逐事件Walk-Forward；没有候选通过全部升级条件，未将历史冠军升级成正式策略，也没有证明未来稳定正期望。

## 1. 架构与数据流

`内容哈希行情 → 完成时点前缀 → 训练内候选评估 → 不可覆盖参数锁 → 唯一执行器连续账户 → 指标/统计 → 离线报告`

核心分工：`core/滚动协议.py`负责时间和选择合同，`application/滚动验证.py`负责研究编排，原 `TurtleBacktester` 仍是唯一复用的多品种执行器；`storage/滚动核验.py`负责制品核验，`observability/滚动报告.py`只读结果，CLI组合它们。没有另造一个回测器获得更漂亮结果。原日报与永续研究功能保留，不能将它们的失败隐藏为“不属于测试”。

## 5. 执行模型、费用与资金约束

以纽约常规时段处理股票，以UTC日线区间处理金属。股票时区转换包含夏令时，但时段来源未认证，半日市/特殊停牌缺失。收盘生成信号，默认该品种下一根Bar开盘成交；延迟按品种自己的实际Bar计数，不被其他市场交易日替代。时间相同先前Bar收盘再后Bar开盘；不同市场未完成的close不参与当前风险预算。

买入提高成交价、卖出降低成交价，手续费单独扣现金，滑点通过持仓成本/PnL体现而不重复扣费。跳空止损按更不利开盘；同Bar止盈止损都触及时先止损。止盈是触价市价退出，不冒充限价单保证价。日线只能知道区间触发，入账时点为该Bar收盘，不捏造分钟精度，也不能据此认证跨市场真实盘中资金释放时序。

全额抵押研究模型、总名义敞口上限1倍、单品种上限0.35倍；每次成交按当时现金和已知价格重算可用资本，不重复花同一份资金。借券证明缺失的股票禁空。股票开盘参与量只用此前已完成Bar成交量，不用当前Bar最终volume；未实现真实盘口队列、逐笔部分成交和停牌成交模型。金属成交量未获可执行量认证。

全部名义敞口按预设年300bp融资计费，空头另300bp借用费，按实际日历时间计算并覆盖周末、计入交易净损益。它是明示保守假设，不是实际融资合同或永续资金费率。权益不足维护门槛时排队到下一开盘减仓，不是交易所级实时强平。极端跳空风险仍可能越过限额；非正净值不伪造CAGR/Calmar。

## 11. 使用、覆盖与复现

先将增量包解压到独立补丁目录，在覆盖前运行：

```bash
python 补丁目录/scripts/覆盖前核验_v2.py --root 本地项目 --manifest 补丁目录/docs/补丁文件清单_v2.json
```

只有BASELINE_MATCH或ALREADY_APPLIED可继续；CONFLICT必须先合并本地改动。覆盖并保留原始data/processed_data后：

```bash
python scripts/旧实验清理_v2.py
python scripts/旧实验清理_v2.py --apply
python scripts/环境核验_v2.py --strict
python -m pytest -q
python scripts/滚动审计复现_v2.py --output outputs/滚动研究_v2
python scripts/回放制品核验_v2.py outputs/滚动研究_v2
```

全项目依赖安装遵循 `python -m pip install -e ".[test]"`；本环境未能联网完成，不能保证仅解压即消除用户环境依赖。研究入口仅依赖实际可用的NumPy/Pandas运行本CSV合同，`--strict`会因为其他必需后端缺失拒绝环境验收。输出目录已存在则拒绝覆盖，请使用新的中文版本目录，不删除旧研究重写历史。

单独核验冻结v4参考可以用 `--iterations 1 --candidate-limit 1 --skip-stress`；这不会证明生产正期望。复现完整研究应不传这些缩减参数。每个真实回放源码版本的Git差异保存在独立证据包；正式代码中不堆积中间实现。
