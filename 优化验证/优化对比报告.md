## 结论

执行真实性和可复现性有明确改善，但没有证据支持把候选参数替换为生产默认值。
预先锁定的 6 组参数在最后 365 天留出集上全部亏损，`best_combination_id` 均未获得确认。
验证集第一名是 1.5N 止损、1.0N 加仓，留出总收益 -1.14%；双倍成本后为 -1.78%。
因此保留经典 20/55 入场、10/20 通道退出及原生产参数，没有用留出集另选赢家，也没有添加固定止盈来美化收益。

原参数 2N 止损、0.5N 加仓，保持数据、仓位预算与成本一致：

| 指标 | 修改前 | 修复后 |
|---|---:|---:|
| 全样本年化收益 | 15.55% | 15.86% |
| 全样本最大回撤幅度 | 49.82% | 30.91% |
| 全样本 Sharpe | 0.610 | 0.901 |
| 完成交易数 | 27 | 76 |
| 最终留出总收益 | -4.95% | -3.21% |

这些变化来自执行修复，不应解释为未来收益预测。修复前的超长持仓和较少交易，部分来自退出单被错误取消。
也存在修复后历史收益下降的组合，见完整比较表；没有筛掉这些结果。

## 逐项执行审计

| 领域 | 发现与处理 |
|---|---|
| 入场与信号时序 | 保持完成 K 线确认、下一可交易开盘执行；通道继续排除当前 K 线。共用突破核，避免投影与实际入场漂移 |
| 出场 | **修复**：入场的跳空/通道失效过滤不能取消风险减少型退出；否则应退出的持仓可能被长时间保留 |
| 止损与跳空 | **修复**：开盘已经穿越既有保护止损时，先执行保护退出，再处理加仓；废止已不存在仓位的加仓意图。开盘检查不读取当天 high/low |
| 盘中止损 | 保持多头取较差的 min(open,stop)、空头取较差的 max(open,stop)；开盘后才使用本 K 线 high/low 检查止损 |
| 止盈 | 保留趋势跟随的通道退出和止损，没有新增固定盈利目标；属于策略思想的保留，不是遗漏 |
| 仓位和资金 | **修复**：逐笔成交重新计算开盘权益，反映前一笔费用；现货买单按含手续费和滑点的现金上限、数量步长截断，资金不足不成交 |
| 手续费和滑点 | 保留显式的现金成本等价模型，每边按名义金额扣 cost_bps+slippage_bps，不再在价格上重复扣；用双倍成本单独压力测试 |
| 资金费/借券费 | **修复**：除了扣现金，还归属到实际持有的 PositionUnit，汇入交易和单元净盈亏；加仓前发生的费用不摊给后来单元 |
| 窗口末端 | **修复**：显式 liquidation 的独立回测遵守 evaluation_end；批次训练、验证和留出窗口显式 mark-to-market，不能因行情结束位置不同而偷偷改变规则 |
| 异常参数 | 非有限初始资金/权重、非整数验证长度明确拒绝；重叠验证窗口拒绝，防止同一段收益被重复复合 |
| 排名与缺失值 | **修复**：相同指标同分、缺失指标安全计分；缺失留出收益不再当作零收益通过 |
| 样本外隔离 | **修复**：参数邻域只依赖验证集；未来全样本破产标记不参与验证资格。留出仅能否决原候选，不能换选其他候选 |

保护止损采用不利跳空价的依据：触发价格不保证成交价格，见 [Investor.gov 的止损订单说明](https://www.investor.gov/introduction-investing/investing-basics/glossary/stop-order)。
历史模拟不能替代真实执行，见 [CFTC 对模拟交易结果的说明](https://www.cftc.gov/LearnAndProtect/AdvisoriesAndArticles/fraudadv_tradingsystem.html)。

本次历史源为 Binance **现货** BTC/ETH OHLCV，故研究计划采用 cash、禁止做空；不把无资金费数据的现货曲线包装成永续合约实测。
手续费 10 bps/边、滑点 5 bps/边是预先固定的研究假设，非账户真实费率；压力测试为 20+10 bps/边。
仍未模拟订单簿深度、部分成交、排队、流动性冲击、借券可用性、合约强平或盘中资金费时点。现有 intraday 触发选项也不代表逐笔盘中撮合。
因此本次证明的是日线模型的真实性改进，而非交易所级仿真完备。
