# 第一轮：契约与正确性 Review

## 发现与修订

- 原审计把三个不同职责的模型视为重复模型；修订为保留模型并增加显式投影。
- 多资产边界曾使用 `CANONICAL_COLUMNS` 名称；修订为
  `MULTI_ASSET_BAR_COLUMNS`，持久化 Schema 只保留一处权威。
- 时间格式存在多种历史表示；新增统一写入和兼容解析，不改历史字节。
- 股票复权词汇粒度不同；保留数据层精确方法，只在 detector 边界做登记映射。

## 验证

数据模型、字段投影、UTC 往返与持久化列测试通过。未知资产类和 naive 时间均
fail closed。

## 遗留风险

风险与执行参数仍由各应用配置维护；任何新增投影调用都必须显式构造设置对象。
