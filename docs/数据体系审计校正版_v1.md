# 数据体系审计校正版

- v3 `UnifiedStore` 是目标存储权威；`DataLake` 是稳定业务接口，不是另一套领域 Schema。
- detector `AssetConfig` 与多资产 `AssetSpec` 是策略/执行边界视图，权威身份来自 `InstrumentConfig`，风险与执行参数不得猜测。
- 多资产 CSV 的 `date/source/spread` 属于兼容边界；持久化前转换为历史行情 `CANONICAL_COLUMNS`，`spread` 可作为扩展列。
- v2 根目录保留只读兼容；迁移不删除、不覆盖来源，只有完整门禁通过才可切换 v3。
- 带版本后缀的模块不自动等于遗留模块；是否弃用以生产引用、兼容合同和等价回归为准。
- 本地逻辑测试不能替代真实 PyArrow、DuckDB、Windows 原子写、Provider 响应和生产数据资产验收。
