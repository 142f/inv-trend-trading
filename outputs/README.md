# outputs

Final, human-facing outputs live here. These files are generated by scripts and
should be treated as reports, not source data.

## Current Layout

```text
outputs/
└── us_trend_alerts/   Daily US trend alert report exports.
```

## File Formats

For the same run, multiple formats may exist:

| Format | Purpose |
|---|---|
| `.md` | Best for reading in the editor or publishing as a report |
| `.csv` | Best for spreadsheet review and filtering |
| `.json` | Best for downstream scripts and automation |

These are not duplicates when they represent the same run in different formats.
