# DuckDB依赖版本核验

日期：2026-10-03；环境：本机Windows/NTFS、CPython 3.12.6、PyArrow 21.0.0。

本项目固定 `duckdb==1.4.5`。1.5.5/1.5.6在不含项目代码的最小子进程中，可在关闭DuckDB内存连接后调用CRT退出时返回0xC0000005，而非指定退出码。准确的DuckDB内部缺陷位置尚未定位；不能将这归因于审批事务实现或直接推断为系统运行库过旧。

| 核验 | 结果 | 记录 |
| --- | --- | --- |
| 1.5.5与1.5.6相同退出路径，各100次 | 异常2次、5次 | `outputs/DuckDB补丁版退出对照_20261003.json` |
| 1.5.6真实崩溃/事务/标记合同 | 20通过、1失败 | `outputs/DuckDB补丁版恢复核验_20261003.txt` |
| 隔离1.4.5退出，100次 | 无异常 | `outputs/DuckDB长期支持版退出对照_20261003.json` |
| 隔离1.4.5退出，另500次 | 无异常 | `outputs/DuckDB长期支持版退出重复核验_20261003.json` |
| 隔离1.4.5真实恢复合同 | 21通过 | `outputs/DuckDB长期支持版恢复核验_20261003.xml` |
| 隔离1.4.5原914项全量 | 914通过、6项已有弃用警告，237.41秒 | `outputs/长期支持版全项目核验_20261003.xml` |
| 1.4.5与1.5.5项目格式双向读取 | current、Repository、版本、行数一致 | `outputs/DuckDB跨版本兼容核验_20261003.json` |
| 实际项目环境安装核验 | `.venv`加载1.4.5 | `outputs/DuckDB验证版本启用复核_20261003.txt` |

保留CRT注入的退出码及到达标记断言，并另测Windows内核终止。两者语义不同：[CRT `_exit` 文档](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/exit-exit-exit?view=msvc-170)、[Windows TerminateProcess文档](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-terminateprocess)。内核终止成功不能替代CRT路径的验证。

兼容测试只涉及本项目生成的Catalog结构和数据格式，未读写用户额外数据库。不保证1.4.5能读取使用了新版特性的任意1.5数据库；升级依赖前须重复退出、崩溃恢复、兼容及全量测试。有限次通过也不能证明所有Windows机器上永无原生缺陷。
