# 数据契约与字段映射 v1

## 权威边界

`inv_trend.data.models.CANONICAL_COLUMNS` 是唯一持久化行情列契约。多资产模块的
`MULTI_ASSET_BAR_COLUMNS` 只是 CSV/回测消费投影，不得作为数据库或 Parquet Schema
版本依据。

| 字段 | 唯一语义 |
|---|---|
| `instrument_id` | 经济价格序列的稳定主键 |
| `symbol` | 应用展示和策略选择使用的业务别名 |
| `source_symbol` | Provider 请求及响应中的来源标识 |
| `asset_class` | 资产大类，不代替市场或合约类型 |
| `market` | 交易场所或报价市场 |
| `instrument_type` | spot、cfd、future、equity、etf、perpetual 等合约类型 |

## 模型投影

- `InstrumentConfig` 是数据身份和来源权威。
- `AssetConfig` 是 detector 的周期、权限和风险消费配置。
- `AssetSpec` 是回测/执行的数量、成本和风险合同。
- 应用层使用 `DetectorSettings`、`ExecutionSettings` 及 `to_detector_asset()`、
  `to_asset_spec()` 显式投影。目标模型专属参数不得从同名近似字段推断。
- `provider_adjusted_close` 到 detector `back_adjusted` 是已登记的词汇映射；原始
  Provider 调整方法仍保留在 `InstrumentConfig`，不能反向覆盖。

## 时间规则

- 内存时间必须是带时区的 `datetime` 或 `Timestamp`，进入业务层后统一为 UTC。
- 新持久化时间使用 RFC 3339 UTC；`to_rfc3339_utc()` 是统一序列化入口。
- `parse_utc_datetime()` 兼容既有 `Z` 与 `+00:00` 制品，但拒绝 naive 时间。
- 日期分区仍使用 `YYYY-MM-DD`。Provider 毫秒时间戳只能在接入边界解码。
- 不重写既有不可变文件、Manifest 或内容哈希。
