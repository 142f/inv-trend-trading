## 3. 真实缺陷、修复与复测

### 缺陷 1：`stable_id` 分隔符碰撞（P3，潜伏）— **已修复**

- 位置：[identity.py:12-15](src/inv_trend/core/identity.py#L12-L15)
- 输入：`stable_id('a|b','c')` 与 `stable_id('a','b|c')`
- 实际：两者均得到 `a52dd81bfd5e4e66d96b9f59`（相等）
- 成因：`"|".join(map(str, parts))` 对含分隔符的参数不做转义，不同参数序列可拼出同一字符串。
- 影响：`stable_id` 用于 report/assessment/observation/anomaly/transition 的 ID（7 处调用）；当前调用点均为「固定标签 + 固定元数」，暂不会触发；若外部把含 `|` 的符号/时间戳传入，会产生 ID 冲突，进而覆盖不可变制品标识。
- 修复建议：改为长度前缀编码或 JSON 序列化：
  ```python
  return hashlib.sha256(json.dumps(list(map(str, parts)), ensure_ascii=False,
                       separators=(',', ':')).encode('utf-8')).hexdigest()[:24]
  ```
  或 `"|".join(f"{len(p)}:{p}" for p in parts)`。**注意**：这会改变所有既有 ID，属于破坏性变更，需独立提交并同步刷新 golden master / 阶段哈希；未获确认前不建议直接改。
0
- **复测证据**：
  - `stable_id('a|b','c') = a76045815fb6f7ba7dc65993`，`stable_id('a','b|c') = e4b36b20c5f883a4c625897f`，不再相等；
  - 7 组真实调用形状（turtle/indicator_episode/breakout_assessment/anomaly_episode/turtle_observation/volatility/单参数）与旧算法逐字节一致；
  - 新增 3 个回归用例（历史 ID 不变、碰撞消除、长度前缀单射），`tests/unit/test_公共能力合同.py` 29 passed；
  - ID 敏感子集（golden_master、core 回归、日报、report_renderer 等）160 passed；
  - 修复后全量回归 **1570 passed / 0 failed**；`ruff --select F` 通过。
- 状态：**已修复并提交**（未改任何对外接口，未刷新历史制品 ID）。
