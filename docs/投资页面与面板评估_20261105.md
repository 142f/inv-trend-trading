## 2. 实际投资视角的缺口（改动前）

| 级别 | 缺口 | 说明 |
|---|---|---|
| **P0** | 无组合风险预算 | 决策面板对每个标的都按"权益 × risk_pct ÷ (stop_n × ATR)"给股数，但 27 个标的同日触发时**没有任何合计口径**：实测若全部按建议股数执行 = 名义 **$295,140（2.95× 杠杆）**、1N 风险 **$13,284（13.28%）**，双双超过策略配置里的 2.0× 与 12% 上限。 |
| **P0** | 无执行票据 | 只有展示，没有"代码/方向/股数/价格/止损"的可复制行或 CSV，实盘要人工二次转录，易错。 |
| **P1** | 跨页统计口径不一致 | 温度面板"今日已触发 72"是**全部评级**，决策面板"已触发 27"是 **A/B 级**，同一快照两个数字，容易误读。 |
| **P1** | 汇总不闭合 | 决策面板汇总只显示三区与失败/预热，27+27+31=85 ≠ 163 标的，缺少"其余/合计"。 |
| **P1** | 无目标位与 R 倍数 | 有止损、有退出通道，但没有"到第一目标/退出通道的距离与 R 倍数"，无法快速比较赔率。 |
| **P1** | 无持仓感知 | 页面不知道当前持仓，无法区分"新建仓/加仓/已持有"，也不会提示"已触发但已持有"。 |
| **P2** | 无板块/相关性聚合 | 配置里有 cluster 风险上限，但面板没有按板块/基金聚合的敞口视图。 |
| **P2** | 无变化追踪 | 不显示"相比上一交易日新增/失效了哪些触发"，日报式使用时需人工对比。 |
| **P2** | 可访问性与移动端 | 卡片是 `div` 点击区域，键盘不可操作；宽表格在手机上依赖横向滚动；没有打印样式。 |

## 3. 本轮已实施（按优先级）

### 3.1 组合执行预算（P0）

- 新增纯函数模块 `application/market_panels/组合风控.py`：按"评级 A > B、分数、ADX、相对量、距离"排序，逐个分配风险预算，并对**总 1N 风险 / 单方向 1N 风险 / 总杠杆 / 单方向杠杆**四项上限裁剪股数，返回可执行清单与被裁剪原因。
- 决策面板新增"组合执行预算"区块：可执行标的数、组合名义、杠杆、1N 风险合计与占权益、多空拆分、预算裁剪明细。
- 未触发/预热不足/无方向的标的进入 `excluded` 并给出原因，便于核对。

### 3.2 今日可执行清单 + 票据（P0）

- 服务端渲染表格（无 JS 也可读）：代码、方向、评级、股数（含"建议 N 股"）、参考价、止损、单笔风险、名义、票据。
- 每行"复制"按钮 + "复制全部票据"（TSV，可直接粘贴到表格/券商下单窗口）+ "导出 CSV"（UTF-8 BOM，Excel 直接打开）。
- 被裁剪的卡片显示"组合裁剪"徽章。

### 3.3 口径统一与汇总闭合（P1）

- 市场聚合新增 `triggered_ab_count`（A/B 级触发数）；温度面板同时展示"已触发（全部评级）"与"已触发 A/B 级（可执行）"，与决策面板一致。
- 决策面板汇总补齐"其余（未评级/未触发）"与"标的合计"，27+27+31+78 = 163 闭合。

## 7. 结论

现有 7 个固定页面中，3 个是工程验收、2 个是研究观察，只有决策面板与温度面板面向交易；本轮把决策面板从"单标的建议"升级为**含组合预算与可执行票据的交易台**，并用真实快照验证了它能把 2.95×/13.28% 的越界敞口收敛到 1.55×/6.47%。仍未解决的是持仓感知、变化追踪与板块聚合，需要新的输入数据（持仓/板块映射）后再做。
