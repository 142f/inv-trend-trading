## 五轮实际迭代

跨轮复查发现的兼容问题也回到相应模块修正，最终再次执行完整回归。

| 轮次 | 实际重构 | 首轮测试与性能 | 问题复查及后续优化 |
|---|---|---|---|
| 1 | 用编译后的 rolling rank 替换逐窗口 Python 回调；中位排名公式保持不变 | 46 项通过；首测 175.62 倍 | 核对重复值、NaN、正负无穷和部分预热窗口；分母按有效有限值计数。继续优化其依赖的指标原语，并最终增加扫描器完整准备链对照，证实收益进入实际调用路径 |
| 2 | 真实波幅使用 NumPy fmax，抽取对齐的数值序列校验；删除 DMI 首元素冗余赋值 | 初测发现空 float32 类型差异，修正后 66 项通过；首测 5.36 倍 | 保留空输入和 nullable 扩展类型的 pandas 路径，避免第一根行情被 NaN 污染；空 DMI 返回完整空结构 |

## 架构、复用和目录职责

- `core/行情校验.py`：只验证内存行情的表结构和时间索引，由特征准备与聚合共同依赖。是否允许非有限价格等数值政策仍由各自边界负责，避免混入交易和 I/O 规则。
- `core/math_utils.py`：统一数值序列验证、真实波幅、百分位及 MACD 组装。MACD 公共函数和特征准备复用同一套组装公式。
- `core/features.py`：负责请求、快照、缓存和特征组合。私有已验证构建入口只由完成校验及指纹的入口调用；不引入全局缓存或跨运行状态。
- `core/performance.py`：负责纯权益数学与回撤时长，提供 EquityAnalysis 供应用层复用；原有 `equity_metric_kernel` 和 `equity_statistics` 继续可用。
- `application/backtest/metrics.py`：保留交易统计、不可用原因、业务命名和输出格式；不再维护另一份权益衍生计算或回撤算法。

本次缩小的是职责重复与算法知识耦合，不用“全库 import 边数减少”替代可验证事实。
core 没有新增对 application、adapters 或 I/O 的依赖；现有分层约束由架构测试继续保护。

## 缺陷修复与兼容边界

证据脚本同时执行固定 Git 基线与当前代码，以下 6 个场景均为旧实现失败、新实现通过：

1. 空 DMI 的首元素赋值引发 IndexError。
2. OHLC 相同、附加字段改变时缓存返回旧字段。
3. OHLC 相同、数据集元数据改变时缓存返回旧元数据。
4. 时间点相同、展示时区改变时缓存返回旧索引。
5. 出现更深且已恢复的回撤，仍沿用较早回撤的恢复时长。
6. 出现更深但未恢复的回撤，仍错误报告已恢复。

另外增加重复列、非整数聚合周期的明确错误；无时区聚合输入按 UTC 解释。
OHLC 数值类型在特征边界明确检查，避免先“通过”字符串检查、随后在指标运算中才失败。
缓存对含附加字段或 attrs 的输入采用重新构建，优先保证输出快照正确；此类输入的缓存命中率可能下降。
纯标准 OHLCV 快照继续按内容和请求缓存，加入列顺序、类型及时区等结构信息；公开 OHLC 指纹算法保持不变。
PreparedBars 的 dataclass 冻结不代表 pandas 对象不可变；调用方仍应遵守现有缓存结果只读约定。

分组高低价保持跳过 NaN 的语义；开收盘保持严格取首尾位置，避免 groupby.first/last 跳过空值而改用其他时间的价格。
浮点结果对照容差为 1e-12；百分位随机参考测试使用精确比较；黄金主数据沿用原有 1e-10 数值容差与精确事件/订单约束。
绩效基准采用单个回撤周期，以独立测量兼容结果的性能；多回撤修复通过上述缺陷场景和随机参考测试单独验证。
