# 海龟入场过滤规则 v1

本实现补齐 `config/滚动验证协议_v2.json` 已声明但原代码没有实现的规则；不是对旧实验结果的重新认证。原策略代码不能接受这些参数，旧摘要不能作为当前引擎的共同数据回放证据。新结果必须绑定实际参数、数据版本和代码哈希，不能覆盖旧冻结实验。

## 参数及语义

| 参数 | 默认值 | 启用后的含义 |
|---|---:|---|
| entry_adx_min | 0 | 大于0时要求当根ADX不低于门槛，缺失/非有限值阻断入场 |
| entry_adx_period | 14 | 复用core中的Wilder DMI/ADX计算；ADX只检查强度，方向由突破与均线决定 |
| entry_confirmation_bars | 1 | 大于1时要求连续N根收盘价均严格越过第一根之前的同一通道；仅支持close触发 |
| entry_atr_percentile_max | 1 | 小于1时要求相对ATR的历史分位不高于门槛，等于门槛通过；未知值阻断 |
| entry_atr_percentile_lookback | 120 | ATR/close的完整尾随窗口，含当根已完成行情，复用core经验中位秩；并列值取中位概率 |
| risk_atr_fraction_target | 0 | 大于0时按min(1, target/(ATR/price))缩减单元风险，再按合约步长向下取整；低波动不放大风险 |

全部过滤与已有均线、方向许可、事件冻结和组合预算同时生效。新过滤用于初始入场；已有加仓均线条件保留。风险缩仓作用于新建的入场和加仓订单，既有持仓不会被该参数追溯重写。默认关闭新过滤，原20/55突破、10/20退出与预算行为保持不变。

## 连续收盘确认

以N=3做多为例：在当前根与此前两根组成的窗口，取第一根之前的entry_period根最高价作为固定上轨。三根收盘都必须严格高于该上轨，加上第一根ATR乘breakout_buffer_n的缓冲。做空镜像使用最低价、减去缓冲。等于边界不确认，未完成或缺失数据不能代替确认。

这个窗口不会把第一根突破产生的新高算入自己的确认门槛，也不会要求后两根再创新高。返回的breakout_level仍为原始固定通道，交给既有PendingOrderIntent/执行器；信号在第N根收盘完成后才可用，成交时点继续由既有下一开盘规则决定。每次评估使用尾随N根窗口，窗口中的任一根失效则不确认；不保存隐含的无限期候选锚点。

## 可复现性与缓存

只有启用的过滤生成额外指标。ADX周期、分位窗口、确认根数、缓冲和既有通道/均线周期进入指标缓存键；阈值变化继续由策略门槛判断。所有特征仅使用当前及以前的行情，指标准备不下载、不读文件、不发送通知。

ADX先完成Wilder预热。ATR分位必须积累lookback个有限ATR/close值，因此n_period=20、lookback=120时最早需要139根行情。预热不足不是低波动或弱趋势的默认认证，而是未知、禁止入场。
