# artifacts

无运行入口的一次性审计快照与历史归档，不是产品页面。

## 布局

```text
artifacts/
├── history/
│   ├── docs/     已退役的验收回执、补丁、评审与历史说明
│   ├── scripts/  已完成的一次性审计/对比脚本
│   ├── 迁移清单_20261103.md
│   └── 目录治理变更摘要_20261103.md
├── refactor-acceptance-s1-s5/  本机预览 PNG（已忽略）；页面与静态资源已迁入 src/
├── 数据管理流水线任务看板_v1.html  本机留存的任务看板快照（已忽略）
└── WORK_PROGRESS.md            本机工作进度记录（已忽略）
```

## 谁写入

各次审计会话写入；这些文件没有生成它们的运行时入口，不能当系统页面复现。

## 谁读取

仅供证据留存与历史追溯。历史归档内的路径按归档时的状态保留，不作为现行入口。

## 什么可以删

归档证据不删除。产品页面在 `deliverables/` 与 `trend-monitor` HTTP 看板，不放本目录。
